# InsuranceApp – Building Insurance Backend

InsuranceApp is a backend API for managing building insurance data for a Romanian insurance company.  
The application allows brokers to manage clients and buildings and is designed with clean architecture and extensibility in mind.

---

## Scope (Current Sprint)

### In scope
- Clients (Individual / Company)
- Buildings (insured objects)
- Geography (Country → County → City)
- Authentication & Authorization (JWT, roles)
- Validation, centralized error handling
- Unit tests and integration tests
